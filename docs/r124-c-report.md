# R12.4-C 桌面帧耗时与资源往返验证报告

2026-11-03，北京时间。使用 R12.4-A 固化的 R12.3 生产构建 `4ec8fQrT8D712RwuHoZOz` 作对照，R12.4-B 独立构建 `kO0oV9gPJnyXqXm_CFobW` 作候选。使用同一台 Windows 主机、同一 Headless Chrome 156.0.8078.74 会话，逐组新建标签并顺序采样。两版本用 localhost 的独立端口隔离站点存储。两版均在相同出生点、相同相机位置和投影、1440×900、固定 high、DPR 1、同样的阴影设置下进入前台采样。机位浮点差异在 1e-8 内。

## 帧耗时

A 为 R12.3，B 为候选版。四组按 A→B→B→A 顺序，每组两段 10 秒。表内为 rAF 帧间隔，包含浏览器调度和渲染节奏。

| 组 | 均值 ms | P95 ms |
| --- | --- | --- |
| A1 | 14.786 / 15.722 | 20.1 / 25.0 |
| B1 | 16.234 / 13.675 | 25.1 / 20.0 |
| B2 | 15.400 / 14.866 | 24.9 / 20.1 |
| A2 | 18.242 / 18.762 | 25.2 / 29.9 |

两版本每秒渲染快照的资源计数一致，场景动画使单帧绘制计数小幅变化。随后以 B→A、A→B 各采两段 10 秒，读取最近一次渲染的 draw calls、三角形、点和线计数，与随后一个 rAF 间隔配对，在相同计数分组内计算均值。该配对衡量固定绘制计数下的帧间隔，GPU 专用计时未采集。

| 相同 draw calls / 三角形 | B→A 均值，A / B ms | A→B 均值，A / B ms |
| --- | --- | --- |
| 634 / 283006 | 20.96 / 17.25 | 11.67 / 14.16 |
| 635 / 283008 | 18.94 / 20.96 | 11.19 / 11.54 |
| 639 / 283016 | 16.63 / 17.56 | 11.42 / 13.83 |

首轮 635 组约 2.02 ms 的差值在反序轮缩至 0.35 ms。634 组方向反转，639 组两轮均偏慢约 0.93–2.41 ms，保留为局部观察项。整体差异随测试顺序及绘制分组变化，且同版自身的跨轮波动较大，现有证据未确认可归因于候选构建的持续回归。两版所有桌面采样均无大于 50 ms 的间隔，未触发产品修改。历史报告的绝对数值只作参考，本轮判断基于同时期对照。

## 24 轮资源往返

候选版在独立标签中通过站内链接完成首页、关于页、首页往返。共 25 个采样点，包含第 0 轮初始样本。102/102 项检查通过，文档时间原点始终一致。第 1–24 轮均为 1 个文档、890 个 DOM 节点、1,597 个 JS 事件监听器、1 个画布和 1 个活动 WebGL 上下文。缓存贴图的 dispose 监听器最大值始终为 2。活动上下文记录的原生对象数量全程稳定，包括 1,123 个 Buffer、24 个 Texture、61 个 Program、8 个 Framebuffer、3 个 Renderbuffer 和 678 个 VertexArray。

往返样本在测量前按既有脚本执行 GC。JS 堆第 1 轮 20.64 MiB，第 16 轮达 23.59 MiB，后段第 17–24 轮为 22.00–22.16 MiB，第 24 轮 22.13 MiB。末段资源计数无逐轮累积，堆曲线与 R12.3 独立往返的预热后回落形态一致。

桌面和资源组均无控制台错误、运行时异常、HTTP 错误、网络失败或取消。保留 Clock 弃用和首组 X4122 精度提示。
