# R12.2-C 北径入口道路与地表融合试点

日期：2026-11-02。范围仅限主岛 `approach-a`：广场至北径桥头的接近铺装。不扩展到其他入口，也不修改跨海 A/M 桥面或 C 径踏板。

## 结果

- 修复铺面只连接左右两列顶点、跨过横坡凹地的问题；采用原路径样本与 `mainIslandSurfaceY` 在路宽内分 8 段取样，宽度与原两侧边界不变。
- 同段横向铺装缝也贴合原高度场；路缘从内侧石色向外侧积雪色过渡，两端恢复原色。未增加岩石、植被或发光装饰。
- 同一组 27 个真实网格采样点中，铺面至可见雪面的间距：最大 **0.2013m → 0.1014m**；范围从 0.0005–0.2013m 收敛至 **0.0793–0.1014m**。
- 真实键盘从出生区进入试点、穿过入口到桥头，再返回；6 次目标到达检查通过。
- 302/302 测试、TypeScript、源码 ESLint、生产构建通过；12 个页面生成完成。
- 修改后采集 0 console error、0 未捕获异常、0 HTTP 错误、0 请求失败；107 条 warning 原样保留。
- 开工前 222 个文件的哈希复核中，只有限定的 4 个文件变化，`unexpectedChanges` 为空。R12.1 岛体/自然资产源码、B 的相机与名牌修改及旧交付截图未改。

## 诊断与取舍

只调整材质不足以解决本轮问题。修改前的实际射线采样发现，路面中央最大高出雪面约 20cm；二维边缘采样形成的直线弦没有经过中间的地形凹处。因此先修正横向网格，再处理材质边界。

没有调整地形函数或移动高度，也没有用装饰物遮住离缝。地形解析面与其低多边形渲染面本身存在近似差异；现有路面还有 0.055m 视觉偏移，雪面网格另有约 −0.035m 下移。本轮保留这些契约，所以仍有约 8–10cm 的铺装抬高量，**不是完全无缝或零间隙**。

## 残留与后续

- 仍保留约 8–10cm 铺装抬高量；全岛其他道路未扩展同类处理。本轮是单段试点。
- 个别玩家近景中信灯贴近画面下沿；本轮没有改动 B 相机逻辑，应在 D 的完整探索流程中一并复核，不能为截图擅自更换玩家机位。
- Three.js 弃用、几何转换、阴影兼容等既有 warning 原样保留；没有以“零错误”声称“零警告”。
- 移动截图是浏览器模拟；未做真机、完整三径至全部项目屿、详情闭环、压力降档或长时稳定性验收。
- 下一步建议进入 **R12.2-D 完整探索与性能回归**，先复核现有成果，再决定是否扩展道路试点。
