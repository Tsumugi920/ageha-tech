## 0. 总体判断

主岛顶面的地貌与布景经过 R7–R11 的多轮打磨，已经是全场景最成熟的部分：
四区性格、路缘压实雪带、岩簇分组、三形态松树都在数据层有依据。
当前画面品质的短板**不在主岛地表本身**，而集中在四个"包裹层"：

1. **远景浮岛是一圈深色剪影**——每张外向构图的左右两侧都挂着深海军蓝"飞碟"，
   把冰蓝世界的整体明度拉低一档（问题 G1）。
2. **冰海是"带方格接缝的浅色平面"**——77m 重复的 canvas 纹理在多数机位读出大方格，
   海天线实为穹顶画带与海盘的拼接弧线（G2/G3）。
3. **主岛岩壁下半部与三屿屿体仍是"规则层叠"语言**——上半部檐口破碎感已经成立，
   下半部依旧 4–5 圈均匀环绕的波浪层；AgehaOS 屿体侧视读成深色浮板堆（G4/G5/G6）。
4. **光照偏"高键"**——雪面大面积近纯白、地貌分区远读弱，同时深色小物件
   （石块暗档、记忆环暗瓣、门架黑杆）以纯黑背光面出现，两头同时失真（G7/G8/G13）。

## 1. 逐区审计（任务书十区域）

### 1.1 主岛地表（截图 01 / 05 / 06 / 07 / 19）

- **问题**：近景可读性已经不错（四区地貌、压实雪带、路缘散布都在起作用）；
  但中远距机位上顶面大片近纯白，西岭/东北丘原/东缘冰碛带的分区只能靠微弱明暗猜；
  前景几块深色岩石以近乎纯黑的背光面出现，在雪面上非常扎眼（01 左下、19 右下）。
- **原因**：① `WORLD_COLORS.snow #F1F8FF` + `SunLight intensity 2.7` + 半球光，
  顶面反照率高、曝光偏"高键"；R10 已把雪面 roughness 提到 0.68 压高光，但整体亮度
  层次仍缺少"中间灰阶"。② 岩石 shade 最深一档颜色过深（接近 rockDeep #10294B 一族），
  `flatShading` 下背光三角面没有环境补光，读成黑块。
- **影响**：初始构图（01）的前景石块、地表分区是"第一眼"内容，直接决定精致感。
- **方向**：① 光照/曝光全局再平衡（见 §1.10）；② 岩石色阶整体上移一档，
  最深色只保留给金属框架类；③ 顶面加"远读层"——把 R11 的风蚀雪脊在顶点色上
  再强化一档（不增几何），让分区在 40m 外可辨。
- **文件**：`components/world/terrain/MainIsland.tsx`（Boulders 色阶、顶面顶点色）、
  `components/world/systems/SunLight.tsx`、`lib/world/constants.ts`。

### 1.2 主岛边缘与底部岩层（截图 02 / 03 / 05 / 12 / 13）

- **问题**：岩壁上半部（雪檐→上部岩层的破碎过渡、嵌入岩、冰棱）已经成立；
  **下半部仍读成"重复叠放的规则圆环"**——4–5 圈水平波浪层均匀环绕 360°，
  层间色差平缓，没有竖向贯通的破口把环带打断（12 号机位最明显）。
- **原因**：`islandGeometry.createLayeredIslandGeometry` 的层剖面沿角度均匀分布，
  R7 的侵蚀沟槽（gully）是"表面附加物"而非"结构性破口"；R11.1 已加逐层相位与
  宽窄节奏，但幅度（±3.5%）不足以打破"环带"读感；色带上
  `ROCK_MID #5A7C99 → ROCK_ABYSS #27496E` 过渡连续，层与层缺乏"跳变"。
- **影响**：主岛是每张侧面构图（02/03/05）的主体，下半部占岩壁面积约 60%，
  是"圆盘感/人工平台感"的最大残留来源。
- **方向**：① 下半部加 2–3 处大型竖向破口/崖缝（把环带在角度上断开，
  类似主岛"岬角式"已有能力的强化版）；② 层带高度引入非均匀"跳层"
  （相邻层高度差突变 1 次，而非均匀波）；③ 沟槽阴影与层间色差再拉开一档；
  ④ 底部尖端周围加岩屑堆（已有 shard 碎块语言的延续）。
  全部在几何生成函数内完成，不增加 segments 预算。
- **文件**：`components/world/terrain/islandGeometry.ts`（profiles/层剖面/rockColor）、
  `components/world/terrain/MainIsland.tsx`（rockGeometry 参数）。

### 1.3 道路、踏板与护栏（截图 03 / 17 / 19）

- **问题**：R11.6 的 C 径踏板几何与衔接**状态良好，本轮保留**。
  残留的"工程模型感"来自三处外围：① C 径门架是"两根白锥 + 一根黑色横杆"（17），
  与全岛晶簇/冰晶语言脱节；② 踏板列等宽等距、厚度一致，侧视（03）读作
  "多米诺骨牌桥"；③ 踏板下方没有任何支撑/悬吊语汇，像悬空摆放。
- **原因**：R11.6 聚焦连接关系与碰撞验收，装饰层未同步；门架复用了最简 primitive。
- **影响**：C 径是西向构图的第二主体，也是玩家停留最久的路径之一。
- **方向**：**只做加法、不碰已验收几何**：① 门架改为"双冰晶柱 + 悬浮导向环"，
  与 trail beacons 同语言；② 踏板侧缘加薄冰裙边或冰棱垂饰（视觉层），
  每 3–4 块做尺寸微差（实例化缩放，不动 `trail-c-curb`/`trail-c-pavement`）；
  ③ 在深水段踏板下方加 2–3 根冰柱支撑（纯视觉，不注册碰撞）。
- **文件**：`components/world/terrain/Trails.tsx`、`components/world/terrain/NorthRouteDressing.tsx`（A 径灯柱语汇参考）。

### 1.4 树木、岩石与自然植被（截图 01 / 05 / 07 / 14）

- **问题**：① 松树三形态（spire/broad/wind）在数据层已区分，但远看全是
  同一深青色剪影，冠层无积雪、无明暗层次；② 14 号机位证实西岭松簇
  被山脊自遮挡——南侧/东南开阔雪原完全没有树，分布南北失衡；③
  FrostGroves 冰冠乔木（白球冠）形态可读但"棒棒糖"感明显。
- **原因**：`PINE_FORMS` 三形态的 tier 颜色都落在同一深青区间；植床
  集中在西岭与北径沿线，是跟随 R11 地貌补植的遗留分布。
- **影响**：植被是"数字花园"命题的核心证据，目前对画面的色彩贡献是
  "一片深色小三角"，辨识度不足。
- **方向**：① 每株冠层顶加积雪帽（顶点色或小几何帽），冠层色向
  青灰-冰绿拉开两档；② 南麓/东南缓坡补 2–3 簇（遵守任务书"重点区域留白"，
  不新增到广场与出生点视线走廊）；③ 冰冠乔木的冠球改为 2–3 球错位组合。
  岩石部分见 §1.1（色阶），布点本身 R9/R11 已经合理，不动。
- **文件**：`components/world/terrain/MainIsland.tsx`（PINES/PINE_FORMS/FrostGroves）。

### 1.5 中央广场（截图 01 / 04 / 07 / 08）

- **问题**：① 广场扇面铺装与四向嵌线在雪面上几乎不可读（07 中需仔细辨认）；
  ② 记忆环未点亮时五瓣呈深蓝灰（`#365F7C`），在广场中心形成一团"黑色花瓣"，
  俯视（04）尤其明显；③ 出生点三片导览鳍过素（07 前景三根白板）。
- **原因**：R10 把石铺装整体压灰以避免过亮，但与雪面的色相差被同步压缩；
  MemoryRing 的 dim 色是按"点亮前深色石材"设计的，没有考虑大俯视角度下的面积占比。
- **影响**：广场是出生动线的第一目的地、俯视构图的正中心。
- **方向**：① 扇面/嵌线相对雪面做 ±8% 明度差（同色相内拉开，不加彩）；
  ② MemoryRing 未点亮瓣改为浅浮雕色（与铺装同调），点亮瓣仍转暖——
  只改 dim/lit 两色，不动五瓣逻辑与探索系统；③ 导览鳍加青色边缘光已有，
  补基座浮雕线即可。
- **文件**：`components/world/terrain/MainIsland.tsx`（PlazaFans/EntranceInlays）、
  `components/world/objects/MemoryRing.tsx`（仅 dimColor/litColor）、
  `components/world/objects/SignPost.tsx`。

### 1.6 AgehaOS 核心地标（截图 09 / 12 / 15 / 19）

- **问题**：**地标本体（兔耳拱 + 菱形核心 + 屏幕）已通过验收，本轮不动**。
  问题在其"底座与环境"：① 屿体（mesa 剖面）侧视读成**深色浮板堆**——
  场景探针确认 03/05/06 中疑似"深色漂浮碎块"的对象就是该屿体
  （`agehaos` 屿 rock mesh，mesa 层薄且平直，背光面近乎剪影）；
  ② 屿顶除到达平台外完全空白——没有岩簇、没有植被（09）；
  ③ 到达平台栏杆是"两根白柱 + 一根黑横杆"，比主岛任何结构都简陋。
- **原因**：屿体共用 `createLayeredIslandGeometry`，mesa 剖面为"平台式"层叠，
  在 60m 外侧视角下层间缝隙读成深色板片；屿面装饰未随 R9–R11 的布景迭代更新。
- **影响**：AgehaOS 是初始视线正前方的景深终点（01/19 正对它），屿体侧影
  出现在 03/05/06 三张侧向构图里。
- **方向**：① agehaos 屿体参数调整：mesa→加大 jaggedness 或改 rooted 剖面 +
  加深竖向错层，让侧影回到"一块裂开的浮岩"读感；② 屿顶补一组
  岩簇 + 2 株松 + 1 组晶簇（沿用主岛散点语言，不碰地标本体与碰撞体）；
  ③ 到达平台栏杆改用 NorthRouteDressing 的柱+灯语汇。
  **此项涉及"已验收地标的环境层"，按任务七纪律单独列出，不与地貌混做。**
- **文件**：`components/world/objects/ProjectIsle.tsx`（isle-agehaos 的 rockGeometry 参数、
  IsleFoundation、到达平台）。

### 1.7 蝴蝶地标（截图 07 / 08）

- **问题**：蝶枢本体（翼面纹理、形体）状态良好。光环是一根素面青色扁环，
  光柱是素面柱——近景（08）两者都读作"未完成的最简 primitive"。
- **原因**：R3 抬升后聚焦在体量与可穿行性，装饰层未跟进。
- **影响**：08 是"地标近景"验收机位；光环/光柱在多数中景构图中可见。
- **方向**：① 光环加分段节点（环上均布小晶体或刻度，与导向浮晶同语言）；
  ② 光柱底部加"鳞粉粒子上升"已有一个菱形浮晶，可再给光柱一个从下到上的
  透明度渐变（去掉"实心管"感）。低优先级，不阻塞其他阶段。
- **文件**：`components/world/objects/ButterflyCore.tsx`。

### 1.8 远处浮岛（截图 01 / 02 / 05 / 06 / 09 / 10 / 15）

- **问题**：五座远景岛全部呈**深海军蓝剪影**，mesa/shard/rooted 三剖面在
  145–160m 距离上只剩"深色飞碟/帽子"一种读感；NW 岛的针塔读成"伞刺"（01/02）。
  它们比主岛岩壁深 2–3 个明度档，与冰蓝世界脱节。
- **原因**：`DistantIsles` 直接复用主岛 ROCK 顶点色带（含 ROCK_DEEP/ABYSS 深带）
  + `roughness 0.95 flatShading`，背光面积占优；雾（near 120 / far 380）在
  145–160m 处只提供约 15–20% 的柔化，不足以把深色"推回大气"。
- **影响**：**每张外向构图的左右两翼**。是"画面整体发灰发闷"感受的第一贡献者，
  也是任务六（空间层次）在远景层的最大缺口。
- **方向**：① 远景岛专用提亮色带（岩体向 #8FA9BE–#B9CEDF 收敛，顶面雪帽
  面积加大），保留 5–8% 的深色点缀做层次；② 针塔替换为"冰晶尖塔"
  （与岛缘晶簇同语言、更细）；③ 可选：给远景层单独一个更近的雾衰减
  （或在顶点色里预混雾色），把"剪影"变"大气透视"。
- **文件**：`components/world/terrain/DistantIsles.tsx`、
  `components/world/terrain/islandGeometry.ts`（rockColor 或新增远景色带参数）、
  `lib/world/layout.ts`（DISTANT_ISLES 数据不动）。

### 1.9 穹顶建筑（截图 03 / 11 / 12）

- **问题**：Moss 穹舱（玻璃穹 + 内部生态 + 观测屏）与茧居所穹窟状态良好，

- **文件**：`components/world/objects/ProjectIsle.tsx`（isle-moss 部分）、`GalleryNook.tsx`。

### 1.10 天空、光照与地面环境（截图 02 / 16 / 18）

- **问题**：① 天空穹本身渐变干净，但**云层几乎不可读**（18 仰视近乎纯空白，
  02 中地平线上下是两块浅色平面硬切）；② 冰海纹理 77m 平铺产生大方格接缝
  （02/04/06/16 清晰可见）——512px canvas 内容不无缝却用 RepeatWrapping repeat 26；
  ③ 海天线实为**穹顶画带与海盘的拼接线**：海盘 ±1000 超出穹顶 r=380，
  真实海面在 ~375m 处被穹顶遮断，16 号机位可见"行星边缘"式弧线下坠；
  ④ 阴影两端失衡——CS 屿白面上观测环腿的影子硬黑生硬（10），
  而广场石台的接触阴影又偏弱（07）。
- **原因**：① CloudLayer sprite opacity 0.56/0.32 + scale 30–58，在 380 穹顶下
  对比过低；② IceSea canvas 渐变底色 + 边缘截断的斑块/裂缝，重复后每格边界
  出现可读直线；③ `seaSize 2000` vs `skyDomeRadius 380` 的尺度不匹配；
  ④ shadow-bias/normalBias 参数为 2048 单级 shadow map 折衷。
- **影响**：天空与海是所有外向构图的背景板，占画面 40–60% 面积。
- **方向**：① 云带 opacity→0.7+/0.45，scale→40–80，在主视线侧翼补 3–4 朵大云；
  ② 冰海改 MirroredRepeatWrapping（立即消除直线缝）或改为世界坐标
  程序化纹理；③ 穹顶海色带与雾色对齐 + 海盘边缘顶点色渐变入雾，
  让"海天线"成为雾的产物而非几何拼接；④ shadow radius/normalBias 微调 +
  主岛关键结构允许 `shadow.radius` 柔化。光照全局：sun 2.7→约 2.3–2.5、
  hemi 补偿，把雪面从"过曝白"拉回"有层次的冷白"（配合 §1.1）。
