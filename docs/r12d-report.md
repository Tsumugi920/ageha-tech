## D 阶段改动（6 文件）

### G1 远景浮岛（收益最大单项）

- `islandGeometry` 新增 **`atmosphereFade`**（0~1，导出可测）：顶点色向雾色调
  `#C6DCEB` 烘焙——远景岛在 145~160m 处真实雾只覆盖 ~12%，此前直接复用主岛
  深色岩带，侧影读成深海军蓝「飞碟」；现岩体 0.42 / 顶面 0.38，剪影变成
  「雾中淡影」，顶面雪色同时收敛（远看不再发白发亮）。
- NW 岛竖向剪影从「细杆伞刺」换成**冰晶尖塔**（锥形塔身 + 顶端发光晶尖，
  与岛缘晶簇同语言）。
- 数据级测试：atmosphereFade 位置逐位不变（只改色）、岩体平均明度 ≥1.15×、
  顶面到雾色调距离收敛 ≥25%。

### G2/G3 冰海与海天线

- 冰海纹理 `RepeatWrapping → MirroredRepeatWrapping`：canvas 渐变与斑块在
  重复边界被硬切断的「77m 方格」消失；anisotropy 4→8。
- 天穹海天线以下的画带从「海色」改为**雾色**（`WORLD_COLORS.fog`）：海盘
  （±1000m）在 ~375m 处被穹顶遮断的拼接线与「行星边缘」弧消失，海盘淡入穹顶。

### G7/G13 曝光与阴影

- 主光 2.7→**2.45**（雪面向阳坡不再顶到近纯白），半球光 0.42→**0.47**、
  冷填光 0.42→**0.46** 补偿（背光面更透气）——总亮度量级不变、方向对比收敛。
- 阴影 normalBias 0.028→**0.032**——白色表面上的硬黑投影边缘再柔半档。

### G10 云带

- 透明度 0.56/0.32 → **0.7/0.45**、云团体量 30–58 → **40–78**——地平线云带
  从「不可读」变成可读的天象层次（仰视天顶仍保持简洁，符合任务书）。

### 测试（`tests/r12d-atmosphere.test.mjs`，新增 4 条）

全套 **275/275** + tsc 0 + eslint 0 + 生产构建通过。
