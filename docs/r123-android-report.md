# R12.3 Android Chrome 真机验证报告

2026-11-03（北京时间）。Android 真机验收已执行，主要探索流程与 15 分钟前台运行通过。Moss World 横屏体验按钮被顶部导航挡住，横屏可操作性验收有一项未通过。iOS Safari 仍待单独接入实测。

## 环境与范围

vivo V2284A（PD2284）、Android 15、Chrome 130.0.6723.102。物理屏幕 1260×2800，CSS DPR 3.5。通过 USB ADB reverse 访问现有 Next.js 生产构建（BUILD_ID `ouFibcU67QQ9toBMztrFH`），通过 USB CDP 采集真实 Chrome 页面。初次接入为 unauthorized，手机授权后变为 device。自动启动 Chrome 的命令被执行策略拦截，用户在手机上手动打开验收页。使用 `?debug=1` 读取场景状态、玩家位置和渲染统计，未覆写视口、DPR 或设备类型。摇杆与 UI 操作为发送到真机 Chrome 的 CDP 触摸事件，方向切换和切到系统桌面由用户在手机上实际操作。

主组原始 CDP 记录 36 条网络响应、0 条 HTTP ≥400、0 条网络加载失败、0 条运行时异常、0 条错误级日志。保留 2 条 Three.Clock 弃用和 9 条 AudioContext 用户手势限制警告。声音功能本次未单独验收。
